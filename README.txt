Project Overview
This project is a web-based "Digitalized Feedback Portal" designed for the students and staff of Universiti Malaysia Pahang Al-Sultan Abdullah (UMPSA). The goal is to modernize the manual complaint process into an efficient, user-friendly digital system.
Key Features:
Home page with institutional branding.
Interactive feedback submission form with validation logic.
Status tracking table with color-coded progress indicators.



How to Run Locally
Since this is a static front-end project, you can run it using any web browser.
1. Extract the Files: Unzip the submitted folder Gary_Assignment1.zip.
2. Open the Homepage: Double-click the index.html file or right-click it and select "Open with" (Chrome, Edge, or Firefox).
3. Navigation: Use the navigation bar at the top to toggle between Home, Submit Complaint, and Track Status pages.
